# 林的工作台

一个安静、有质感的个人每日工作台：计划、打卡、灵感和复盘都在一个页面完成。

## 功能

- 每日空白计划：按当天需要新增任务
- 任务完成打卡、进度统计与删除
- 灵感随手记
- 马伯庸极简日记：今日事件、今日阅读、今日美食、今日新知
- 登录同一账号后，手机与电脑自动同步
- 网络中断时继续保存在当前浏览器，恢复后同步
- 响应式桌面与手机布局

## 本地运行

```bash
pnpm install
pnpm dev
```

## GitHub Pages

仓库包含自动发布流程。推送到 `main` 分支后，在仓库 Settings → Pages 中选择 **GitHub Actions** 作为 Source，即会自动部署。
